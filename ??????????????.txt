# 更换设备重新部署流程操作说明

> 换新电脑后，几分钟就能继续开发和使用这个项目。

## 一、换电脑继续开发（完整流程）

1. **复制整个 `TransLedger` 文件夹**到新电脑（U 盘 / 网盘 / 微信传输均可），放到任意位置（如桌面）
2. **新电脑打开该文件夹**，用 opencode（或任何 AI 工具）打开这个文件夹 → 它会自动读 `AGENTS.md` 了解项目
3. **发布时**（如需更新线上网页）：
   ```
   powershell -ExecutionPolicy Bypass -File "新电脑上的路径\publish.ps1" -Version v1.1 -Message "说明"
   ```
   - `publish-config.json` 已含 Repo Token，直接可用；若 Token 过期，到 GitHub 重建后更新此文件
4. 之后一切照常：改、发消息、「发布新版本」

## 二、换设备日常使用（不需要任何文件）

任何新手机/新电脑，只要：
1. 浏览器打开 https://xion-darren.github.io/ledger/
2. 设置页填 Access Token → 点「测试连接并保存」
3. 选「我的账本」或「家人账本」

数据就自动同步过来，无需复制任何文件。

## 三、换电脑后数据会不会丢？

**不会。** 数据存在 GitHub 私有数据仓库（ledger-data / Hledger-data），与电脑无关：
- 旧电脑数据：在云端，新设备首次配置后自动拉取
- 本地 localStorage 只是"主存储副本"，云端是权威备份

## 四、必须记住的三样东西（都在项目文件夹里）

| 文件 | 作用 | 注意 |
|---|---|---|
| `publish-config.json` | Repo Token（发布代码用） | 内含密钥，别外传 |
| `TOKENS` | 记录各类 Token 的备忘 | 内含密钥，别外传 |
| `AGENTS.md` | 给 AI 的项目说明书 | 可随意复制 |

> 若上述含 Token 的文件丢失或泄露：到 github.com/settings/tokens 重建 token，更新 publish-config.json 即可。
